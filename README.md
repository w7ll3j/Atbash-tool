# Atbash-tool

A small command-line tool that encrypts or decrypts text with the Atbash cipher. You type text in the terminal and get the result back.

Built while practicing input(), functions, loops and string methods.

## Usage

`uv run .\atbash.py`

## Example

Input: `Fake password = FakePassword123!` \*

Output: `Fzpv kzhhdliw = FzpvPzhhdliw123!`


\**This project is for fun and learning only. The Atbash cipher has no key and a fixed letter mapping, so it is easy to break and should not be used to protect real data. Real systems protect passwords with hashing instead of encryption.*
