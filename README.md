# Atbash-tool
 
A small command-line tool that encrypts or decrypts text with the Atbash cipher. Type text in the terminal and get the result back.
 
## Installation
 
Requires Python 3 or uv. No other packages are needed
 
## Usage
```
python3 atbash.py
```
*or*
```
uv run atbash.py
```
 
```
Input:  Fake password = FakePassword123!
Output: Fzpv kzhhdliw = FzpvPzhhdliw123!
```
 
This project is for fun and learning only. The Atbash cipher has no key and a fixed letter mapping, so it is easy to break. Real systems protect passwords with hashing, not encryption.
